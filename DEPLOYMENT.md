# JOTAF Earth Movers

Responsive public website for JOTAF Earth Movers in Zvishavane, Zimbabwe.

## Deployment

Connect this repository to the **existing** Netlify site. Build command: leave empty. Publish directory: `.` (repository root). `index.html` must be at root.
